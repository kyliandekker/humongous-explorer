
# Humongous Explorer

A resource explorer for Humongous Entertainment game archives.

## Features

- Browse HE0 and .(A) archive contents.
- View room backgrounds.
- Play and export audio (talkies, SFX, songs) with waveform visualization.
- Palette display of backgrounds and images.

## Building

Requires CMake 3.20+ and MSVC (C++20).

Just run generate.bat.
